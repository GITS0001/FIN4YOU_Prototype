Yes — combining the HackerRank dataset with the AgamiAI Indian Bank Statements dataset can be good for FIN4YOU. But use them for different purposes. Neither dataset alone will train a complete Artha AI.
1. How to use both datasets


HackerRank dataset — Financial intelligence
Use it for:
- Financial profiles and transaction histories.
- Affordability and payment-option decisions.
- Financial calculations and recommendation scenarios.
- Testing whether Artha AI can answer questions using backend results.


AgamiAI dataset — Statement processing
Use it for:
- Testing extraction from supported bank-statement formats.
- Handling Indian transaction descriptions and debit/credit entries.
- Testing the statement-upload pipeline.
- Checking how extracted transactions flow into your categorization model.

2. Which models will benefit?
Model/component	How the datasets help
Statement parser	AgamiAI provides additional statement examples, depending on their available formats and annotations.
Transaction categorizer	Both may help if they contain compatible, trustworthy category labels. Otherwise, use only labeled records for supervised training.
Expense forecasting	Use HackerRank histories if they contain sufficient continuous dates per user. Statement examples do not automatically provide suitable time-series data.
Affordability engine	HackerRank is the primary source for testing decisions and payment options.
Artha AI LLM	Both datasets provide financial context and test cases, but they do not directly train the LLM.
RAG embeddings	Use a separate, curated financial knowledge base; transaction CSVs are not a replacement for it.

4. My advice for your hackathon
Don't spend your 18 hours merging huge datasets or training multiple models just to say you used more data.
1. Verify the AgamiAI dataset's formats, labels, and license.
2. Test whether its extracted transactions can be mapped to your existing transaction schema.
3. Train or evaluate categorization only on compatible labeled data.
4. Use the existing HackerRank data for affordability and decision-making.
5. Connect Artha AI to those results using tool calling; add RAG only if the core flow is working.
One crucial check: your competition rules may restrict external datasets. Confirm that AgamiAI is permitted before using it in the submitted prototype.
